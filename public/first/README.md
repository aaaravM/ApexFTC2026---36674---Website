# Official FIRST® / BIOBUZZ™ logo files

These PNGs are the official, unmodified files supplied by FIRST (FTC logo pack and the
BIOBUZZ™ 2026–27 logo pack). Rules (FIRST Branding & Design Guidelines, CANOPY guide):

- Never recolour, filter (no CSS invert/grayscale), crop, rotate, animate or redraw them.
- Use the `_reverse` / `_white` files on dark backgrounds and the standard files on light ones.
- Minimum sizes: FTC horizontal ≥ 60 px tall; BIOBUZZ lockup/wordmark ≥ 336 px wide.
- Always show them next to "Apex Robotics · Team 36674".
- Keep clear space around them; no busy backgrounds (no 3D scene behind a logo).
